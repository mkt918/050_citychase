# シティチェイス (City Chase)

警察vs犯人の非対称対戦ボードゲームのWebアプリ版。Firebaseによるオンライン対戦に対応。

## 🎮 ゲーム概要

**シティチェイス**は、犯人1人と警察チーム(ヘリコプター3機)に分かれて対戦する推理ゲームです。

### ルール

#### 犯人側

- 5x5のビル街を移動
- 移動するたびに痕跡チップを残す
- 既に痕跡を置いた場所には戻れない
- 11ラウンド逃げ切れば勝利

#### 警察側

- ヘリコプター3機を操作
- 各ヘリは「移動」または「調査」のどちらか1つを実行
- ビルを調査して痕跡または犯人の車を発見
- 犯人の車を発見するか、犯人を包囲すれば勝利

## 🚀 プレイ方法

### モード

- **ローカル対戦** — 同じ画面で2人が交代プレイ
- **AI対戦** — 1人でAIの犯人を追う
- **オンライン対戦** — Firebase Realtime Database + 匿名認証で、6桁の部屋コードを使い遠隔の相手と対戦

### ローカルで実行

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# ビルド
npm run build
```

### デプロイ

```bash
# Firebase Hosting へデプロイ (メイン)
npm run build
firebase deploy --only hosting

# GitHub Pages へデプロイ (サブ)
npm run deploy:gh-pages
```

## ⚠️ オンライン対戦の既知の制約

このアプリはサーバーレス構成（Cloud Functionsなし）のため、`database.rules.json` は
「匿名ログイン済みなら誰でも読み書き可能」という単純なルールになっています。つまり：

- 部屋コード（6桁）を知っている、あるいは推測した第三者が観戦・改ざんできる可能性があります
- 対戦相手はゲーム状態を技術的には参照可能です（ローカル対戦がブラウザのメモリ上で完結するのと
  同様、「信頼できる相手との対戦」を前提とした実装です）

参加者のuidに書き込みを限定するルールも検討しましたが、Realtime Databaseのトランザクション書き込みと
相性が悪く安定しなかったため、シンプルなルールを採用しています。友人・知人との対戦を想定した設計です。
